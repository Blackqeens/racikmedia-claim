✓ Terpasang ✓ Seluruh 46 Halaman ✓ Auto-detect English ✓ Cache terjemahan per sesi ✓ localStorage

Alur Kerja Sistem

1
Halaman dimuat → cek preferensi manual di localStorage["rm_lang"]
↓
2
Ada pilihan manual → pakai langsung (ID/EN), tanpa deteksi otomatis.
↓
3
Tidak ada pilihan manual → periksa bahasa browser. Hanya awalan en yang mengaktifkan terjemahan otomatis.
↓
4
Browser bahasa Inggris → English. Bahasa lain (termasuk Jepang/Prancis) → default Indonesia, tanpa panggilan terjemahan otomatis.
↓
5
Cache sesi sessionStorage digunakan lebih dulu. Hanya teks yang belum tercache yang dikirim ke Gemini.
↓
6
Pengguna klik dropdown → ganti bahasa manual → simpan ke localStorage → berlaku di seluruh halaman.

Menyiapkan terjemahan otomatis

Terjemahan otomatis memerlukan secret server Gemini dan daftar origin situs produksi yang diizinkan. Untuk pengembangan lokal melalui HTTP, origin loopback (localhost, 127.0.0.1, atau [::1]) diizinkan oleh fungsi. Jangan menaruh GEMINI_API_KEY di file JavaScript atau HTML.

supabase secrets set GEMINI_API_KEY=<API_KEY_GEMINI> APP_ALLOWED_ORIGINS=https://dapper-bienenstitch-b63263.netlify.app
supabase functions deploy translate-page

Origin harus berisi skema dan host saja, tanpa path; untuk beberapa domain, pisahkan origin dengan koma dan jangan gunakan *. Setelah mengubah secret, deploy ulang fungsi. Pilihan bahasa disimpan lintas halaman; cache terjemahan teks disimpan per sesi browser. Teks UI dan konten dinamis yang tampil dapat dikirim ke Gemini saat pertama kali diterjemahkan. Elemen identitas/nama yang tidak boleh dikirim dapat diberi class notranslate atau atribut translate="no".

Catatan: fungsi memvalidasi origin dan ukuran permintaan serta memakai batas frekuensi best-effort per instance. Karena endpoint diakses pengunjung publik, pasang juga rate limit/kuota di gateway dan batasi anggaran Gemini; cache fungsi bersifat sementara.

Cara Menambah Terjemahan ke Elemen HTML

Tidak perlu ubah JS. Cukup tambahkan atribut data-id dan data-en langsung ke elemen HTML mana saja.

① Teks biasa (heading, paragraf, span, button)

<!-- Teks default = Indonesia. Saat EN dipilih, JS ganti isinya -->
<h2 data-id="Artikel Terbaru"
     data-en="Latest Articles">Artikel Terbaru</h2>

<p data-id="Dibuat oleh komunitas"
   data-en="Made by the community">Dibuat oleh komunitas</p>

② Placeholder input & textarea

<input data-ph-id="Cari artikel..."
       data-ph-en="Search articles..."
       placeholder="Cari artikel..." />

③ Blok konten berbeda per bahasa (show/hide)

<!-- Hanya blok yang cocok dengan bahasa aktif yang ditampilkan -->
<div data-lang-show="id">
  Konten panjang dalam Bahasa Indonesia...
</div>

<div data-lang-show="en">
  Full content in English...
</div>

④ aria-label (aksesibilitas)

<button data-aria-id="Tutup menu"
        data-aria-en="Close menu"
        aria-label="Tutup menu">✕</button>

Referensi Atribut

TargetAtributKeterangan
Teks elemendata-id / data-enMengganti textContent elemen

Show/hide blokdata-lang-show="id" / "en"Tampilkan blok, sembunyikan yang lain

Memasang di Halaman Baru

Untuk setiap halaman HTML baru, tambahkan 3 bagian ini:

1 · Di <head> — link CSS

<link rel="stylesheet" href="../../assets/css/lang.css" />
<!-- Sesuaikan path ../../ dengan kedalaman folder halaman Anda -->

2 · Di dalam navbar — widget HTML

<div id="lang-switcher">
  <button id="lang-trigger" aria-haspopup="listbox" aria-expanded="false">
    <span id="lang-trigger-flag">🇮🇩</span>
    <span id="lang-trigger-label">ID</span>
    <svg class="lang-chevron" viewBox="0 0 10 10" fill="none"
         stroke="currentColor" stroke-width="1.8">
      <path d="M2 3.5l3 3 3-3" stroke-linecap="round" stroke-linejoin="round"/>
    </svg>
  </button>
  <div id="lang-dropdown" role="listbox">
    <div class="lang-dropdown__header">Bahasa / Language</div>
    <button data-lang-option="id" role="option" type="button">
      <span class="lang-opt__flag">🇮🇩</span>
      <span class="lang-opt__name">Indonesia</span>
    </button>
    <button data-lang-option="en" role="option" type="button">
      <span class="lang-opt__flag">🇬🇧</span>
      <span class="lang-opt__name">English</span>
    </button>
  </div>
</div>

3 · Sebelum </body> — load JS

<script src="../../assets/js/lang.js"></script>

Public API — Debug & Kontrol via Console

PerintahFungsi
RMlang.get()Kembalikan bahasa aktif saat ini → "id" atau "en"
RMlang.set("en")Paksa ganti ke bahasa tertentu + simpan ke localStorage
RMlang.reset()Hapus pilihan manual dan deteksi ulang berdasarkan bahasa browser (English saja untuk auto-translate)
Catatan: pilihan manual disimpan lintas halaman. Hasil terjemahan disimpan per bahasa/teks di sessionStorage dan tidak dibagikan ke tab atau sesi browser lain.
💡 Tips: Karena localStorage persisten, pengguna Indonesia yang pernah berkunjung tidak akan kena fetch IP lagi di kunjungan berikutnya — respons instan tanpa latensi.

  </div>
