Penerjemahan Otomatis

Mengapa pilihan bahasa belum menerjemahkan seluruh situs, apa yang sudah diverifikasi, dan apa yang perlu dilakukan sebelum fitur diaktifkan.

Status dokumen: Draft untuk analisis lanjutan  ·  Tanggal: 5 Oktober 2026

Kesimpulan singkat — BELUM berfungsi penuh untuk pengunjung.

Pilihan bahasa dan penyimpanan preferensi sudah berjalan. Namun layanan terjemahan otomatis di backend belum merespons: pengujian endpoint yang dikonfigurasi menghasilkan HTTP 404 — Requested function was not found. Karena itu teks situs tidak bisa diterjemahkan sungguhan sampai fungsi dideploy ke proyek Supabase yang benar dan konfigurasi server disiapkan.

Makna hasil tersebut

Pengunjung dapat memilih Indonesia, English, atau 中文. Preferensi disimpan sehingga dapat dipakai di halaman lain. Engine juga mempunyai jalur untuk mengirim teks ke endpoint penerjemah. Tetapi jalur itu berhenti ketika layanan belum tersedia; UI tidak dapat menghasilkan terjemahan dengan sendirinya.

Catatan penting: tes browser dengan respons tiruan hanya membuktikan bahwa UI bisa mengganti bahasa dan memulihkan teks sumber. Tes itu bukan bukti bahwa request sungguhan sudah mencapai Gemini atau bahwa biaya/API Gemini sudah aktif.

Yang sudah tersedia di implementasi

  • Preferensi bahasa lintas halaman melalui localStorage.
  • Bahasa Inggris dan Mandarin sederhana dikirim ke fungsi penerjemah; label yang memiliki terjemahan manual dapat memakai atribut data-id, data-en, dan data-zh.
  • Teks halaman, konten dinamis, placeholder/label tertentu dapat diproses; hasil teks dapat di-cache per sesi browser.
  • Endpoint contoh disiapkan di supabase/functions/translate-page/index.ts; Gemini API key dirancang berada di secret server, bukan HTML/JavaScript publik.

02 · Rencana aktivasi

Langkah agar terjemahan sungguhan berfungsi

  1. Pastikan proyek Supabase tepat. Cocokkan URL proyek pada konfigurasi browser dengan proyek tempat fungsi akan di-deploy.
  2. Siapkan kredensial secara aman. Simpan Gemini API key sebagai secret Edge Function; jangan pernah menaruhnya pada HTML, JavaScript, atau PDF publik.
  3. Daftarkan origin produksi dan pengujian. Isi APP_ALLOWED_ORIGINS dengan origin persis, misalnya https://domain-situs. Untuk tes lokal, jalankan situs lewat server lokal HTTP dan daftarkan origin seperti http://localhost:5500.
  4. Deploy Edge Function translate-page ke proyek yang sama dengan konfigurasi browser.
  5. Uji request live. Pastikan tidak lagi 404; cek hasil terjemahan, log function, batas penggunaan, dan error dari Gemini.
  6. Uji seluruh alur pengguna. Pilih EN/中文, pindah halaman, muat konten dinamis, kembali ke ID, dan verifikasi halaman yang gagal menampilkan pesan yang jelas.

Contoh perintah deployment (setelah CLI terhubung ke proyek)

supabase secrets set GEMINI_API_KEY=<API_KEY_GEMINI> APP_ALLOWED_ORIGINS=https://domain-situs-anda,http://localhost:5500
supabase functions deploy translate-page

Perintah ini belum dijalankan. Ganti origin contoh dengan domain sungguhan, dan jangan menulis nilai secret ke repository atau dokumen ini.

Hal yang perlu diputuskan sebelum produksi

  • Anggaran dan batas pemakaian: endpoint publik berpotensi menerima permintaan berulang. Batas di memori per instance bersifat best-effort, tidak setara rate limit terpusat.
  • Privasi teks: teks antarmuka dan konten yang terlihat dapat dikirim ke Gemini untuk diterjemahkan. Konten sensitif harus dikecualikan secara eksplisit.
  • Jangkauan istilah “seluruh web”: teks biasa dan atribut terpilih dapat diterjemahkan. Gambar, teks di dalam gambar/PDF, canvas, serta format angka/mata uang/waktu belum otomatis dilokalkan.
  • Kualitas editorial: terjemahan mesin dapat keliru pada istilah lokal, nama produk, konteks budaya, harga, atau informasi hukum. Hal kritis sebaiknya memakai terjemahan yang ditinjau manusia.

Checklist tindak lanjut

  • Konfirmasi URL proyek Supabase dan akses deployment.
  • Tentukan domain/origin produksi serta origin lokal yang akan dipakai.
  • Konfigurasi secret Gemini dan kebijakan kuota/anggaran.
  • Deploy fungsi; pastikan endpoint bukan 404 dan lolos uji CORS.
  • Uji EN dan 中文 dengan request Gemini nyata.
  • Tinjau privasi, pembatasan penyalahgunaan, dan istilah konten.
